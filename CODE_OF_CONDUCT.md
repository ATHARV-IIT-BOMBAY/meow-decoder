# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, and keep criticism about the work. Harassment, insults and personal attacks
aren't welcome in issues, pull requests, discussions or anywhere else the project lives.

To report a problem, open a [private security advisory](https://github.com/ATHARV-IIT-BOMBAY/meow-decoder/security/advisories/new)
(it reaches only the maintainer) or message the maintainer, @ATHARV-IIT-BOMBAY, on GitHub. Reports are kept confidential.
